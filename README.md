# BVRIT-Learning

A comprehensive learning platform for BVRIT (B V Raju Institute of Technology) students featuring an interactive dark-themed interface with modern animations and extensive educational resources.

## Features

- **Academic Resources**: Organized by departments (CSE, ECE, EEE, etc.)
- **Interactive Quizzes**: Practice tests in various programming languages (C, Java, Python, HTML)
- **Video Tutorials**: Comprehensive learning materials for multiple technologies
- **E-Library Access**: Digital resource repository
- **Modern UI/UX**: Dark theme with GSAP animations
- **Responsive Design**: Mobile-friendly interface
- **Contact Information**: Developer and contributor profiles

## Technology Stack

- HTML5/CSS3
- JavaScript (ES6+)
- GSAP Animation Library
- Font Awesome Icons
- Google Fonts

## Project Structure

- `/about` - Information about BVRIT
- `/academic` - Department-wise academic resources
- `/contact` - Developer profiles and contact information
- `/e-library` - Digital library resources
- `/quizes` - Interactive programming quizzes
- `/tutorials` - Technology tutorial sections
- `/videos` - Video-based learning materials

## Development

This project is developed and maintained by BVRIT students and faculty to provide a centralized learning platform for the institution.
